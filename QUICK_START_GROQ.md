## ⚡ 3-Step Setup

### 1️⃣ Get Free API Key (2 min)
Go to: **https://console.groq.com/keys**
- Sign up (email/Google/GitHub)
- Copy API key

### 2️⃣ Add to .env (1 min)
```env
GROQ_API_KEY=gsk_your_key_here
```

### 3️⃣ Restart Server (< 1 min)
```bash
npm start
```
